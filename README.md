# 🧯 עמדות כיבוי אש — קיבוץ גשר

אפליקציית מפה לניהול עמדות כיבוי האש בקיבוץ, עבור **כיתת הכוננות**.

## מה היא עושה

- **מפת לוויין** של הקיבוץ, עם סמן לכל עמדת כיבוי
- רואים במבט אחד **איפה יש עמדה ואיפה חסרה**
- רואים **מה עבר בדיקה, מה פג תוקף, ומתי הבדיקה הבאה**
- כפתור **"נבדק היום"** — לחיצה אחת בשטח מעדכנת את התאריך ומקדמת שנה קדימה
- הדפסת דוח מסודר, וגיבוי לקובץ

## איך משתמשים

1. לוחצים **➕ הוספת עמדה**, ואז על המקום המדויק במפה
2. ממלאים שם, מבנה, סוג ותאריך בדיקה
3. אפשר לגרור סמן כדי לתקן מיקום
